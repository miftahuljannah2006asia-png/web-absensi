Hubungkan Google Spreadsheet Anda

Status: Belum Terhubung ke Sheet Anda
Website saat ini masih memakai URL demo. Agar data presensi masuk ke Google Drive Anda, ikuti panduan 4 langkah di bawah ini.
4 Langkah Mudah Pasang Google Sheet: Buka sheets.new
  1. Buka file Google Sheets baru di sheets.new, beri nama file "Presensi Kelas".
  2. Klik menu Ekstensi (Extensions) > Apps Script. Hapus isi kode bawaan, lalu klik tombol di bawah untuk menyalin kode script backend.
  3. Klik tombol biru Deploy (Terapkan) > New deployment (Penerapan baru):
    • Pilih jenis (Select type): Web app
    • Execute as: Me (email saya)
    • Who has access: Anyone (Siapa saja) — Wajib pilih Anyone agar Google tidak memblokir browser!
  4. Klik Deploy > Authorize access (Pilih Akun Google Anda > Advanced > Go to Untitled > Allow) > Salin URL Web App yang berakhiran /exec.
Pastikan berakhiran /exec (bukan /edit atau /view).

Diagnostik Sistem & Solusi Masalah

Jika terjadi kendala saat pemindaian atau sinkronisasi, periksa status modul berikut:

1. Memori Penyimpanan Browser (LocalStorage)
Aktif & Siap. Data kehadiran dan 90+ mahasiswa tersimpan aman secara offline.
2. Perangkat Kamera & Izin Iframe
Kamera memerlukan izin browser. Jika preview iframe memblokir kamera, klik tombol "Tab Baru" di kanan atas untuk membuka di halaman penuh, atau gunakan tombol "Scan dari Foto/File".
3. Koneksi Google Apps Script (Spreadsheet / SQL)
Mengecek endpoint API...
Tips Mengatasi Status Gagal / Offline:
  1. Deploy Web App: Buka Google Sheets Anda > Ekstensi > Apps Script > Pasang google-apps-script.js > Deploy > Pilih Who has access: Anyone (Wajib).
  2. Kamera Diblokir: Klik tombol "Tab Baru" di atas untuk menjalankan kamera di luar iframe.
  3. Tanpa Kamera: Gunakan tombol "Scan dari Foto/File" atau "Input Manual" atau "Uji Coba Presensi". Data tetap tersimpan 100% normal.
